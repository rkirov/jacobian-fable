# Design: cech-cohomology (`Jacobian/Cech/`)

Blueprint unit **cech-cohomology**. Realizes **CC8** (Čech `H¹` for `O_D`): germ-valued cochains
over finite covers, the complex, refinements, chart-disk covers, `H⁰(𝒰,D) ≃ L(D)`, the global
`H¹(D)` as a **directed colimit** over finite covers (`Module.DirectLimit`), and the
skyscraper/χ interface consumed by finiteness-and-chi and laurent-tails.

This unit is the launchpad of the cohomology spine. Its consumers (blueprint entries read):
**dbar-solvability** (disk acyclicity of the cover-level complex), **dolbeault-comparison**
(Leray theorem + `H¹ ≅ H^{0,1}`), **finiteness-and-chi** (Schwartz finiteness on cover-level
`H¹`, χ ledger via the skyscraper fragment), **laurent-tails** (`H¹(D) ≅ T[D]/im α_D`),
**cech-h1-genus**, **serre-duality-cech** (pairing against concrete cocycles). §11 gives the
per-consumer map.

References: Forster §12 (book 96–104 = PDF 102–110; cochains 12.1, `H¹(𝒰)` 12.2, refinement
independence 12.3, **injectivity 12.4**, colimit 12.5, Leray 12.8, `H⁰` 12.10);
Miranda Ch. IX §3 (book 290–298 = PDF 302–310; full-product cochains Def 3.1, refinement
Lemmas 3.9–3.11, adapted covers Ex. 3.6, direct limit p. 295) and Ch. VI §3 pp. 186–188
(PDF 198–200; what the tail/Serre consumers do with `H¹(D)`).

Substrate: `docs/design/meromorphic-and-divisors.md` (authoritative; the unit is being built to
that design): `MeroGermOn X U`, `restrict` (AlgHom + presheaf laws), `ord`/`evalAt` rigidity
(`ord_restrict`, `evalAt_restrict`), `exists_glue`/`glue_unique`, `LinSysOn D U`,
`restrict_mem_linSysOn`, `mem_linSys_iff_forall_restrict`, `Divisor`, `degree`.

All mathlib names verified by reading source at the pin
(`.lake/packages/mathlib/Mathlib/...`), and the two riskiest Lean shapes compiled in the spike
(§10): the `Module.DirectLimit` typeclass stack over a cover-structure index, and the
Pi-of-submodules cochain/quotient/`mapQ` skeleton.

## 2. Design decisions

### D1 — CC8 call: **colimit over finite covers** (not Leray-relative). Rationale.

We define `H¹(D) := Module.DirectLimit` of cover-level `H¹(𝒰, D)` over the refinement preorder
on finite covers. Reasons, in order:
1. **The spike compiled the entire typeclass stack first try** (§10): refinement `Preorder` on a
   cover structure, classical `DecidableEq`, `IsDirectedOrder` by pairwise meets,
   `DirectedSystem` by refinement-independence, `of/lift/exists_of/of.zero_exact`. The feared
   DirectLimit pain did not materialize.
2. A Leray-relative definition (`H¹ := H¹(𝒰₀, D)` for a fixed good cover) makes *every*
   downstream comparison (χ ledger between different adapted covers, tail comparison, Serre)
   carry a cover-change lemma whose proof **is** the colimit machinery anyway — the work is not
   avoided, just smeared. With the colimit, cover-changes are `of_f`-rewrites.
3. The definition of `H¹(D)` must not depend on the ∂̄ facts (Leray needs disk acyclicity =
   dbar-solvability, which *builds on this unit* — a Leray-relative definition would either
   invert the DAG or leave `H¹` cover-dependent until Dolbeault lands).
4. Forster 12.4 / Miranda IX.3.11 (refinement maps are injective on `H¹` — a sheaf-axiom
   argument, no analysis) makes `toH1 𝒰` injective for every cover, so cover-level statements
   transfer to the colimit losslessly; consumers get both views free.
Fallback chain if assembly stalls: §9.1.

### D2 — Cover type: a small structure over `Fin n`, relative to an ambient open `Ω`

```lean
structure FinCover (Ω : Opens X) : Type u where
  n : ℕ
  U : Fin n → Opens X
  le_base : ∀ i, U i ≤ Ω
  covers : ∀ x ∈ Ω, ∃ i, x ∈ U i
```
- **Smallness**: `FinCover Ω : Type u` (same universe as `X`) — no `Σ (ι : Type), …` universe
  bump, no proper-class issues; `Module.DirectLimit` applies verbatim. This is the canonical
  small index demanded by the task; the "(center, chart, radius)" encoding is *not* needed for
  smallness and would exclude non-good covers, which we want in the index (D4).
- **Relative ambient `Ω`**: dbar-solvability needs the cover-level complex on a *chart disk*
  (disk acyclicity), and dolbeault-comparison's Leray proof (Forster 12.8) works with the
  induced covers `(U_i ⊓ V_α)_α` of the member `U_i`. Making the cochain layer `Ω`-relative is
  free (the mero substrate is already relative) and saves both consumers from rebuilding it.
  The **colimit is taken at `Ω = ⊤` only** (compactness lives there; nobody needs a colimit on
  a disk).
- Empty members are allowed (harmless; `MeroGermOn X ∅` is trivial); `IsGood` members are
  automatically nonempty.

### D3 — Refinement preorder: **finer = larger**; transition maps by classical choice

```lean
def IsRefIdx (𝒰 𝒱 : FinCover Ω) (τ : Fin 𝒱.n → Fin 𝒰.n) : Prop := ∀ k, 𝒱.U k ≤ 𝒰.U (τ k)
instance : Preorder (FinCover Ω) where le 𝒰 𝒱 := ∃ τ, IsRefIdx 𝒰 𝒱 τ
```
`𝒰 ≤ 𝒱` iff `𝒱` refines `𝒰`; transition maps go `H¹(𝒰) → H¹(𝒱)` for `𝒰 ≤ 𝒱`, matching
`Module.DirectLimit`'s variance. It is a genuine preorder, **not** a partial order (mutually
refining covers differ) — exactly what mathlib requires. `DecidableEq (FinCover Ω)` is
`Classical.decEq` (spiked; everything here is noncomputable anyway). The transition map for
`h : 𝒰 ≤ 𝒱` restricts cochains along the **chosen** index map `chosenRefIdx h := h.choose`;
Forster 12.3 (refinement independence, §6.6) shows the induced `H¹`-map is independent of the
choice, which is precisely the `DirectedSystem` instance (`map_self`, `map_map`) — the
cochain-homotopy lemma is load-bearing here, not decorative.

### D4 — Good (chart-disk) covers are a **cofinal class**, not the index type

```lean
def IsChartDisk (V : Opens X) : Prop :=
  ∃ (x : X) (r : ℝ), 0 < r ∧ x ∈ V ∧ (V : Set X) ⊆ (chartAt ℂ x).source ∧
    chartAt ℂ x '' V = Metric.ball (chartAt ℂ x x) r
def FinCover.IsGood (𝒰 : FinCover Ω) : Prop := ∀ i, IsChartDisk (𝒰.U i)
```
Indexing the colimit by *all* finite covers makes directedness trivial and canonical (pairwise
meets, `finProdFinEquiv` — spiked); an intersection of two chart-disks is generally *not* a
chart-disk, so a good-covers-only index would need the compactness shrinking argument inside
the `IsDirected` instance. Instead, good covers enter as a **cofinal family**
(`exists_good_refinement`, compactness + chart-disk basis, §6.3–6.4): every `H¹(D)` class has a
good-cover representative, which is all any consumer needs. Same pattern for **adapted** covers
(each point of a given finite set in exactly one member — Miranda IX Ex. 3.6), the tool for the
skyscraper fragment (§6.7) and for laurent-tails.

### D5 — Cochain convention: **full products over ordered tuples** (Forster/Miranda), no skew
subtype, no `i < j` ordering

`C⁰ = Π i, O_D(U_i)`, `C¹ = Π (i,j), O_D(U_i ⊓ U_j)`, `C² = Π (i,j,k), O_D(U_i ⊓ U_j ⊓ U_k)`
with `(δ⁰f)_{ij} = f_j − f_i`, `(δ¹f)_{ijk} = f_{jk} − f_{ik} + f_{ij}` (all after restriction).
Justification (Lean-cleanliness):
- δ⁰, δ¹, and refinement maps are **uniform formulas with zero case splits and zero signs to
  choose** — `LinearMap.pi` of composites of restrictions and projections (spiked skeleton).
  An ordered-pairs (`i < j`) convention forces order case-splits in δ¹ and in every refinement
  map (τ need not be monotone!); an alternating-subtype convention adds a submodule condition
  to be re-verified by every construction.
- Skew-symmetry is a *theorem about cocycles* (`f_ii = 0`, `f_ij = −f_ji` after restriction,
  from the cocycle relation with `i=j=k` / `k=i` — Forster p. 97), exported at the `ord`-level
  where consumers use it (§4.2). The factor-2 redundancy in `C¹` costs nothing: no dimension
  is ever counted on `C¹` (finiteness counts `H¹` images and windows).
- Both references use exactly this convention, so proofs transcribe literally.

### D6 — Cross-open bookkeeping: reduce to pointwise `ord`/`evalAt` via rigidity

All membership predicates (`LinSysOn`, cocycle bounds, window classes, ML data) are pointwise
`ord`-inequalities, and mero's `ord_restrict`/`evalAt_restrict` make `ord`/`evalAt` invariant
under restriction. **Policy**: every proof that compares sections living on different opens is
reduced to (i) germ-level equalities after restriction to a common lower bound, manipulated
with the one workhorse lemma `Z1.rel_res` (§6.6) and the simp set
`[restrict_restrict, restrict_mk, map_sub, map_add]`, or (ii) pointwise `ord` facts. The only
place a propositional set-equality transport is needed (gluing targets `⋃ᵢ ↑(U i)` vs `↑Ω`,
`U ⊓ U` vs `U`) is packaged once as
`MeroGermOn.congrSet (h : U = V) : MeroGermOn X U ≃ₗ[ℂ] MeroGermOn X V`
(built from `restrict` both ways + presheaf laws; `Compat`, §8).

### D7 — Skyscraper interface: **abstract local windows, no Laurent-coefficient recursion**

For `p : X` the window is a *quotient of germ submodules on the chart source*
(`WindowAt p d d'`, §4.5), and the truncation `windowMap : L(D') →ₗ Window D D'` is
`Quotient.mk ∘ restrict` — purely structural. Laurent coefficients appear **only** in the
dimension count `finrank (WindowAt p d d') = (d'−d).toNat`, proved via an explicit basis of
tail-germ classes `θ_{p,m} = [(z−z_p)^m]` and the **one-step leading-coefficient functional**
`leadCoeff p m := evalAt ((tailGerm p (−m)) * ·) p` (reusing mero's `evalAt` rigidity; no
iterative coefficient extraction, no principal-part machinery — that stays in laurent-tails).
The connecting map `Window → H¹(D)` goes through the reusable **Mittag-Leffler atom**
`mlClass` (§4.6): a 0-cochain in `O_{D'}` whose coboundary is `O_D`-bounded yields a class in
`H¹(D)`; both the χ fragment here and laurent-tails' `T[D] → H¹(D)` are instances.

### D8 — What is proved here vs. recorded as interface

- Proved here: `H⁰ ≃ L(D)`; refinement independence (12.3); **refinement/`toH1` injectivity
  (12.4 — sheaf-axiom only, no analysis)**; colimit assembly + vanishing criteria; good/adapted
  cover existence; the full six-term skyscraper fragment (no `H²` anywhere, §6.7).
- Recorded interface, proofs elsewhere: **Leray surjectivity** — for `[CompactSpace X]` and
  `𝒰.IsGood`, `Function.Surjective (toH1 D 𝒰)` (with injectivity from here this is Forster
  12.8; proof belongs to **dolbeault-comparison**, which owns disk acyclicity); disk
  acyclicity itself (`Subsingleton (H1Cover D 𝒱)` for covers `𝒱 : FinCover Ωdisk`) belongs to
  **dbar-solvability**. NOT this unit: Schwartz finiteness, Dolbeault, `H¹ = g`, any `H²`.


### 4.1 `Covers.lean`

```lean
structure FinCover (Ω : Opens X) where
  n : ℕ
  U : Fin n → Opens X
  le_base : ∀ i, U i ≤ Ω
  covers : ∀ x ∈ Ω, ∃ i, x ∈ U i

def FinCover.single (Ω : Opens X) : FinCover Ω          -- n = 1, U = fun _ => Ω
instance : Nonempty (FinCover Ω)
def IsRefIdx (𝒰 𝒱 : FinCover Ω) (τ : Fin 𝒱.n → Fin 𝒰.n) : Prop := ∀ k, 𝒱.U k ≤ 𝒰.U (τ k)
instance : Preorder (FinCover Ω)                        -- 𝒰 ≤ 𝒱 ↔ ∃ τ, IsRefIdx 𝒰 𝒱 τ
theorem le_def : 𝒰 ≤ 𝒱 ↔ ∃ τ, IsRefIdx 𝒰 𝒱 τ
noncomputable def chosenRefIdx (h : 𝒰 ≤ 𝒱) : Fin 𝒱.n → Fin 𝒰.n
theorem chosenRefIdx_spec (h : 𝒰 ≤ 𝒱) : IsRefIdx 𝒰 𝒱 (chosenRefIdx h)
def FinCover.meet (𝒰 𝒱 : FinCover Ω) : FinCover Ω      -- pairwise ⊓ over finProdFinEquiv
theorem le_meet_left / le_meet_right
instance : IsDirectedOrder (FinCover Ω)
noncomputable instance : DecidableEq (FinCover Ω)       -- Classical.decEq

-- chart-disk covers ([ChartedSpace ℂ X])
def IsChartDisk (V : Opens X) : Prop                    -- D4 formula
def FinCover.IsGood (𝒰 : FinCover Ω) : Prop := ∀ i, IsChartDisk (𝒰.U i)
theorem exists_chartDisk_basis {x : X} {W : Set X} (hW : W ∈ 𝓝 x) :
    ∃ V : Opens X, IsChartDisk V ∧ x ∈ V ∧ (V : Set X) ⊆ W
theorem exists_chartDisk_closure_basis [T2Space X] {x : X} {W : Set X} (hW : W ∈ 𝓝 x) :
    ∃ V : Opens X, IsChartDisk V ∧ x ∈ V ∧ closure (V : Set X) ⊆ W ∧
      IsCompact (closure (V : Set X))
theorem exists_good_refinement [CompactSpace X] (𝒰 : FinCover (⊤ : Opens X)) :
    ∃ 𝒱, 𝒰 ≤ 𝒱 ∧ 𝒱.IsGood
/-- Compact-closure good refinement — the nested-cover input for finiteness-and-chi. -/
theorem exists_good_refinement_closure [CompactSpace X] [T2Space X]
    (𝒰 : FinCover (⊤ : Opens X)) :
    ∃ 𝒱 (τ : Fin 𝒱.n → Fin 𝒰.n), IsRefIdx 𝒰 𝒱 τ ∧ 𝒱.IsGood ∧
```

## 5. `H¹(D)` assembly — proof plan (Colimit.lean)

1. `DirectedSystem` instance: `map_self` — `resH1' (le_refl 𝒰) = resH1 (chosen τ₀) = resH1 id
   = id` by `resH1_indep` + `resH1_id`; `map_map` — `resH1' h' ∘ resH1' h = resH1 (τ∘σ) …`
   (`resH1_comp`) `= resH1' (h.trans h')` (`resH1_indep`). Both are two-rewrite proofs given
   §6.6; this is where 12.3 earns its keep.
2. `toH1 := Module.DirectLimit.of ℂ (FinCover ⊤) _ _ 𝒰` — the spike verified this exact
   call shape with the classical `DecidableEq` and structure index.
3. `exists_rep` := `exists_of` (`Nonempty` from `FinCover.single ⊤`, directedness from meets).
   `exists_rep_good/refined`: refine the produced cover (`exists_good_refinement`, meets), push
   with `toH1_resH1'` (`of_f`).
4. `toH1_injective`: if `toH1 𝒰 c = 0`, `of.zero_exact` gives `h : 𝒰 ≤ 𝒱` with
   `resH1' h c = 0`; `resH1_injective` (12.4) gives `c = 0`. `subsingleton_H1_iff`: (⇐) by
   `H1.induction_on` + each `toH1 𝒰 c = toH1 𝒰 0`; (⇒) injectivity embeds `H1Cover` in a
   subsingleton.
5. `H1Incl := Module.DirectLimit.map (fun 𝒰 => h1CoverIncl D 𝒰 h) hcomm`. `hcomm` asks

   componentwise restriction/inclusion composite **for the same `chosenRefIdx h`** (D3 makes

   `Submodule.inclusion`/`restrictL` commutation (`restrictL_apply_coe` + mero's

## 6. Proof plans for the hard items

### 6.1 `H⁰(𝒰, D) ≃ LinSysOn D Ω` (H0.lean; blueprint ⚠ discharged by mero's rigidity)

Forward `toC0`: restriction along `le_base`; lands in `ker d0` by `restrict_restrict` (both
components of `d0` become the restriction to `U i ⊓ U j` of the same φ).
**Injectivity**: if `toC0 φ = toC0 ψ` then `restrict φ = restrict ψ` on every `U i`;
`glue_unique` over the family `fun i => ↑(𝒰.U i)` (union `= ↑Ω` by `covers` + `le_base`, via
`congrSet` on `Set.iUnion` vs `↑Ω`) gives φ = ψ.
**Surjectivity**: `f ∈ ker d0` means `restrict inf_le_left (f i) = restrict inf_le_right (f j)`
for all i, j (unfold `d0_apply`, move the subtraction) — exactly `exists_glue`'s `hcompat`.
Get `Φ : MeroGermOn X (⋃ i, ↑(𝒰.U i))`, transport along `congrSet` to `MeroGermOn X ↑Ω`.
Membership `Φ ∈ LinSysOn D ↑Ω`: for `x ∈ Ω` pick `i` with `x ∈ U i`;
`Φ.ord x = (restrict Φ).ord x = (f i).ord x ≥ −D x` by `ord_restrict` rigidity + the glue
property `restrict Φ = f i` — **this is precisely the rigidified-normal-form route; no
patching of raw functions ever happens** (mero §6.5–6.6 did that work once). Restricting back:
`toC0 Φ = f` componentwise from the glue property. Global corollary: compose with the
`LinSysOn D univ ↔ LinSys D` bridge (`mem_linSys_iff_forall_restrict`).

### 6.2 Adapted refinement (Covers.lean)

Given `𝒰 : FinCover Ω`, `S : Finset X` (with `S ⊆ Ω` in applications — take `S ∩ Ω` inside the
lemma via the `O`-hypothesis), `O : X → Opens X` with `p ∈ O p`: members of `𝒱` are
- for each `p ∈ S`: `A_p := O p ⊓ 𝒰.U (i p) ⊓ (⊤ \ (S \ {p}))` where `i p` is a chosen member
  containing `p` (from `covers`) and the last factor is the open complement of the finite set
  `S \ {p}` (`[T1Space X]`, `Finset.closed`);
- for each `i`: `B_i := 𝒰.U i ⊓ (⊤ \ S)`.
Index `Fin (𝒰.n + S.card)` via `finSumFinEquiv`/`Finset.equivFin`. Covering: `x ∉ S` is in some
`B_i`; `p ∈ S` is in `A_p`. Adaptedness: `p ∈ S` is in no `B_i` and in `A_q` only for `q = p`.
Refinement: `A_p ≤ 𝒰.U (i p)`, `B_i ≤ 𝒰.U i`. The `O`-clause holds since only `A_p` contains
`p`. Pure finite-lattice bookkeeping; no compactness.

### 6.3 Chart-disk basis and closure basis (Covers.lean)

`exists_chartDisk_basis`: `e := chartAt ℂ x`; `e '' (interior W ∩ e.source)` is open in ℂ
(`OpenPartialHomeomorph` maps open subsets of source to opens) and contains `e x`; pick
`r > 0` with `ball (e x) r` inside; `V := e.symm '' ball = e ⁻¹' ball ∩ e.source` (open), and
`e '' V = ball` by injectivity on source. Closure version (`[T2Space X]`): pick `r` with
`closedBall (e x) r ⊆` the open image, then use `V' := ` preimage of `ball (e x) (r/2)`;
`K := e.symm '' closedBall (e x) (r/2)` is compact (continuous image), hence closed (T2), and
`V' ⊆ K ⊆ W`, so `closure V' ⊆ K` is compact. `exists_good_refinement(_closure)`: for each
`x ∈ X` apply the basis lemma inside a chosen `𝒰`-member; `IsCompact.elim_finite_subcover`
(with `isCompact_univ`) selects finitely many; package with `Finset.equivFin`, recording for
each selected disk the `𝒰`-member it sits in (this is the `τ`).

### 6.4 Refinement maps and functor laws (Refinement.lean)

`resC1` component `(k,l)`: `restrictL` along `𝒱.U k ⊓ 𝒱.U l ≤ 𝒰.U (τ k) ⊓ 𝒰.U (τ l)`
(`inf_le_inf (hτ k) (hτ l)`). `resC1_comp_d0` is componentwise `restrict_restrict` (both sides
are the restriction of `f (τ l) − f (τ k)` to `𝒱.U k ⊓ 𝒱.U l`). `Z1`/`B1` preservation:
`Z1` via `Z1.rel_res` at `W := 𝒱.U k ⊓ 𝒱.U l ⊓ 𝒱.U m ≤` the τ-triple; `B1` via
`resC1 (d0 g) = d0 (resC0 g)` — **equality, not cohomology** (Forster p. 98). `resH1 :=
Submodule.mapQ _ _ (resZ1.restrict …)` — the exact `mapQ`/`restrict` shape spiked.

### 6.6 Refinement independence, 12.3 (Refinement.lean) — the DirectedSystem key

Fix a cocycle `f ∈ Z1 D 𝒰` and two refining maps `τ, τ'`. Define `h ∈ C0 D 𝒱` by
`h_k := restrictL (le : 𝒱.U k ≤ 𝒰.U (τ k) ⊓ 𝒰.U (τ' k)) (f (τ k, τ' k))`
(`le` from `hτ k`, `hτ' k`; membership in `LinSysOn D` by `restrict_mem_linSysOn`).
Claim: `resC1 τ hτ f − resC1 τ' hτ' f = d0 h`. Componentwise at `(k,l)`, everything restricted
to `W := 𝒱.U k ⊓ 𝒱.U l`, which is `≤ 𝒰.U (τ k) ⊓ 𝒰.U (τ l) ⊓ 𝒰.U (τ' k) ⊓ 𝒰.U (τ' l)`:
apply `Z1.rel_res` at `W` for the triples `(τ k, τ l, τ' l)` and `(τ k, τ' k, τ' l)`, subtract:
`f_{τk,τl} − f_{τ'k,τ'l} = f_{τl,τ'l} − f_{τk,τ'k} = h_l − h_k` wait — signs: the two relations
give `f_{τl,τ'l} − f_{τk,τ'l} + f_{τk,τl} = 0` and `f_{τ'k,τ'l} − f_{τk,τ'l} + f_{τk,τ'k} = 0`;
subtracting, `f_{τk,τl} − f_{τ'k,τ'l} = −f_{τl,τ'l} + f_{τk,τ'k} = h_k − h_l = −(d0 h)_{kl}`
(with our `(δh)_{kl} = h_l − h_k`). So the difference is `d0 (−h) ∈ B1` — exact Forster 12.3
transcription; sign conventions resolved *here* so the builder doesn't re-derive them.
Then `resH1 τ hτ = resH1 τ' hτ'` by `H1Cover.mk_eq_zero_iff` on the difference.
`resH1_id`/`resH1_comp` hold already at the `Z1` level (`restrictL_id`, `restrictL_restrictL`).

### 6.7 Refinement injectivity, 12.4 (Refinement.lean) — sheaf axioms only

Let `f ∈ Z1 D 𝒰` with `resC1 τ hτ f = d0 g`, `g ∈ C0 D 𝒱`. For fixed `i`, the family over `k`
of `h_{i,k} := restrictL (f (i, τ k)) + restrictL (g k) ∈ LinSysOn D ↑(𝒰.U i ⊓ 𝒱.U k)`
is compatible on overlaps: on `(𝒰.U i ⊓ 𝒱.U k) ⊓ (𝒰.U i ⊓ 𝒱.U l)` the difference is
`f_{i,τl} − f_{i,τk} − (g_l − g_k)`; `Z1.rel_res` on `(i, τ k, τ l)` gives
`f_{i,τl} − f_{i,τk} = f_{τk,τl}` there, and `f_{τk,τl} = g_l − g_k` on `𝒱.U k ⊓ 𝒱.U l ⊇` the
overlap (hypothesis, restricted). So `exists_glue` (mero) over `fun k => ↑(𝒰.U i ⊓ 𝒱.U k)`
yields `h_i : MeroGermOn X (⋃ k …)`; the union is `↑(𝒰.U i)` (𝒱 covers Ω ≥ U i), transport by
`congrSet`; `h_i ∈ LinSysOn D ↑(𝒰.U i)` pointwise by `ord_restrict` (each `x ∈ U i` is in some
`𝒱`-member). Finally `f_{ij} = h_j − h_i` on `U i ⊓ U j`: both sides restrict equally to every
`U i ⊓ U j ⊓ 𝒱.U k` (compute: `h_j − h_i = f_{j,τk} + g_k − f_{i,τk} − g_k = f_{j,τk} − f_{i,τk}
= f_{i,j}`… sign: `Z1.rel_res` on `(i, j, τ k)`), and these sets cover `U i ⊓ U j`, so
`glue_unique` (uniqueness half) gives equality in `MeroGermOn (U i ⊓ U j)`. Hence `f ∈ B1`.
Note: only `exists_glue`/`glue_unique` (sheaf axioms) are used — no compactness, no analysis.
If this file balloons, the *statement* is kept and the proof may be deferred one milestone —
`toH1_injective` is not on the critical path of dbar-solvability (risk R4).

### 6.8 Window dimension (Window.lean)

`ordGe` is a submodule (`ord_add ≥ min`, `ord_smul`, `ord_zero = ⊤`). `tailGerm p m :=
MeroGermOn.mk (fun x => (chartAt ℂ p x − chartAt ℂ p p) ^ m) h` — meromorphy on the chart
source via `meromorphicAtX_iff_of_mem_source` (mero) + planar `(z − c)^m` (`MeromorphicAt.zpow`
of `analyticAt_id.sub const`); prelim planar lemma
`meromorphicOrderAt_sub_zpow : meromorphicOrderAt ((· − c) ^ (m : ℤ)) c = m`
(from `meromorphicOrderAt_eq_int_iff` with unit `g ≡ 1`), giving `ord_tailGerm_self` through
`ord_mk` + `ordAtX_eq_of_mem_source`. `leadCoeff p m ψ := ((tailGerm p (−m)) * ψ).evalAt p`:
the product has `ord ≥ (−m) + m = 0` (`ord_mul`), so `evalAt` is honest; linearity from
`evalAt_add/smul` guarded by the ord bound; `leadCoeff_eq_zero_iff` from mero's
`evalAt_eq_zero_iff` (§1.4(b)) + `ord_mul` arithmetic in `WithTop ℤ`.
**`finrank_windowAt`**: the classes `[θ_m] := WindowAt.mk (tailGerm p m)` for
`m ∈ Finset.Ico (−d') (−d)` form a basis.
*Independence*: if `Σ a_m [θ_m] = 0` with some `a ≠ 0`, let `m₀` be minimal with `a_{m₀} ≠ 0`;
`ψ := Σ a_m θ_m ∈ ordGe p (−d)`… but `leadCoeff p m₀ ψ = a_{m₀}` (normalization
`leadCoeff p m (θ_m) = 1`, and `leadCoeff p m₀ (θ_m) = 0` for `m > m₀` by
`leadCoeff_eq_zero_iff`), while `mk ψ = 0` forces `ord ψ ≥ −d > m₀`, so
`leadCoeff p m₀ ψ = 0` — contradiction.
*Spanning*: strong induction on `d' − d`: given `[ψ]`, `c := leadCoeff p (−d') ψ`;
`ψ − c • θ_{−d'} ∈ ordGe p (−d'+1)` (by `leadCoeff_eq_zero_iff`), conclude by the IH for the
window `(d, d'−1)` mapped into `(d, d')` (the canonical `Submodule.inclusion`-induced map on
quotients). Then `Module.finrank_eq_card_basis` + `Nat.card_Ico`. `finrank_window`:
`Module.finrank_pi_fintype` + `degree` as the sum over `diffSupp` (mero's `degree` definition
+ `toNat` bookkeeping for `0 ≤ D' − D`).

### 6.9 The six-term fragment (Skyscraper.lean)

Setup: `S := diffSupp D D'` and always also adapt to `S' := S ∪ (supp D) ∪ (supp D')` — the
larger finite set kills the non-effective-`D` corner (points with `D x ≠ 0` never lie in an
off-diagonal pair intersection). All covers below are `IsAdapted S'` refinements produced by
`exists_adapted_refinement` with `O`-parameters recorded per use.

(a) **`mlClass`**: `g : C0 D' 𝒰` with `(d0 g).MemLD D` gives `C1.retype (d0 g) ∈ Z1 D 𝒰`
(cocycle: `d1` of a retyped coboundary vanishes — check componentwise at `ord`/germ level via
`restrictL` naturality of the retype, which is `Subtype`-repackaging, `rfl`-adjacent);
`mlClass := toH1 𝒰 (H1Cover.mk …)`. `H1Incl_mlClass`: under `inclC1` the retype returns to
`d0 g ∈ B1 D' 𝒰`, so the `H1Cover D' 𝒰`-class is 0.
`mlClass_res`: `resC1` commutes with `d0`/retype (§6.4), classes agree by `toH1_resH1`.

(b) **`mlClass_eq_zero_iff`** (the engine, used by exactness at `Window` and by laurent-tails):
(⇐) given φ: `g_i − res φ ∈ LinSysOn D (U i)` componentwise (the ord hypothesis), and
`d0` of that `C0 D 𝒰`-cochain retypes to the same `Z1 D 𝒰` element (res φ cancels in
differences), so the class is `H1Cover.mk (d0 …) = 0`, hence `mlClass = 0`.
(⇒) `toH1_injective` + `H1Cover.mk_eq_zero_iff`: `retype (d0 g) = d0 h` for some
`h ∈ C0 D 𝒰` **on 𝒰 itself** (injectivity spares us the refinement!). Then
`(g_i − ι h_i)` is a `d0`-kernel element of `C0 D' 𝒰` (differences vanish: compute in
`MeroGermOn (U i ⊓ U j)`), so §6.1 (H⁰) glues it to `φ ∈ LinSysOn D' ⊤ ≃ LinSys D'`; the ord
estimate `ord(g_i − φ) ≥ min(ord(g_i − ι h_i − (φ − …)), …)` — directly: on `U i`,
`g_i − res φ = ι h_i` (glue property), which is `D`-bounded. ✓

(c) **`exists_realization`**: choose representatives `ψ_q := (w q).out`; for each `q`, an open
`O_q ∋ q` inside the chart source where `ψ_q` has no pole off `q` (mero's
`eventually_ordAtX_eq_zero/top` on a representative) and meeting no other point of `S'`;
`exists_adapted_refinement` from `FinCover.single ⊤` with these `O`; set `g` on the unique
`q`-member to `restrict ψ_q`, elsewhere `0`. `MemLD` of `d0 g`: off-diagonal intersections
avoid `S'` (adapted), where `D = D' = 0` and both `ψ`-restrictions are pole-free by the `O`
choice; diagonal components vanish. `Realizes`: difference is 0 or `ψ_q − ψ_q`.

(d) **Lemma A / `mlClass_eq_of_realizes`**: two realizing data `(𝒰, g)`, `(𝒰', g')`; take a
common refinement 𝒲 that is again `S'`-adapted with members at `q` inside both `O`-zones
(one more `exists_adapted_refinement` call on `𝒰.meet 𝒰'`). On 𝒲, `resC0 g − resC0 g'` is
componentwise `D`-bounded: at the unique `q`-member, `ord_q ≥ −D q` since both differences
against `ψ_q^{out}` are (`Realizes`, `ord_add`-min); at non-`q` points and other members,
`D = 0` bounds hold by pole-freeness. Hence the two `Z1 D`-retypes differ by
`d0(retype (resC0 g − resC0 g'))`, same `H1Cover`-class, same `mlClass` after `mlClass_res`.
**Linearity of `windowConnect`** then follows: realize `w`, `w'` on a common adapted cover
(construction (c) is cover-flexible); `g + g'` realizes `w + w'` because
`(w+w').out − (w.out + w'.out) ∈ ordGe q (−D q)` (quotient arithmetic) and `ord_add`;
`map_smul` likewise. Package `windowConnect` as a `LinearMap` from the raw function +
`map_add'`/`map_smul'` via Lemma A.

(e) **Exactness at `Window`** (`exact_windowMap_windowConnect`): `windowConnect w = 0` ⟺
(via (b) applied to a realizing `g`) `∃ φ ∈ L(D')` with `g_i − res φ` `D`-bounded ⟺ the
window class of `φ` at each `q` equals `w q` (unfold `Realizes` + `WindowAt.mk_eq_zero_iff`,
triangle via `ord_add`) ⟺ `w ∈ range (windowMap h)`.

(f) **Exactness at `H¹(D)`** (`exact_windowConnect_H1Incl`): (⊇ range) is `H1Incl_mlClass`.
(⊆) `ξ` with `H1Incl h ξ = 0`: represent `ξ = toH1 𝒱 [f]` on an `S'`-adapted 𝒱 (exists_rep +
adapted refinement + `toH1_resH1`); `H1Incl ξ = toH1 (h1CoverIncl [f]) = 0`, so by
`toH1_injective` (on the `D'` system!) `ι f ∈ B1 D' 𝒱`: `ι f = d0 g'`, `g' ∈ C0 D' 𝒱`.
Set `w := ` window vector of `g'` (at each `q`, the class `WindowAt.mk (restrict g'_{k(q)})`
of the unique member's component — `ord ≥ −D' q` holds since `g' ∈ C0 D'`). Then `g'`
realizes `w` and `(d0 g').MemLD D` (it equals `ι f`), so
`windowConnect w = mlClass 𝒱 g' = toH1 𝒱 [retype (d0 g')] = toH1 𝒱 [f] = ξ`. ✓
(g) **`H1Incl_surjective`**: given `ξ' = toH1 D' 𝒱 [f']` with 𝒱 `S'`-adapted (refine + push):
each off-diagonal component of `f'` is supported away from `S'` where `LinSysOn D = LinSysOn
D'` pointwise, and diagonal components have `ord = ⊤` (`Z1.ord_diag`); so `f'` retypes to
`Z1 D 𝒱` and `h1CoverIncl` maps its class to `[f']`. Push with `H1Incl_toH1`. **No `H²`, no
long exact sequence, no snake lemma anywhere.**

χ-ledger note for finiteness-and-chi: from the fragment, once `FiniteDimensional` of the four
outer terms is known (their theorem), `finrank L(D') − finrank L(D) + finrank H¹(D) −
finrank H¹(D') = finrank (Window) = (deg D' − deg D)` by rank-nullity on the five maps — they
assemble it; we deliver the exactness and `finrank_window`.
