## Assembling the PR

```bash
python3 scripts/make_pool_pr.py          # writes build/pool-pr/
python3 scripts/make_pool_pr.py --check  # staleness check
```

That emits `LeanPool/JacobianDiffgeo.lean` + `LeanPool/JacobianDiffgeo/**` with the module prefix
rewritten (`Jacobian.* → LeanPool.JacobianDiffgeo.*` — only `import` lines change, since the
library never names its own modules elsewhere), plus the `projects.yml` card as a fragment to
splice in. After copying into a pool checkout, run `lake exe mk_all`.

The generated tree has **not** been compiled inside a pool checkout; the rewrite is the same one
the lean-eval overlay uses, which does build, but that is an inference, not a test.

## What is left

1. **`genus`'s "unused" instance arguments.** mathlib's `unusedArguments` linter flags
   `[T2Space X] [CompactSpace X] [ConnectedSpace X]` on `genus`. Those binders are fixed by
   Buzzard's challenge statement, which this library also has to satisfy (they appear verbatim in
   lean-eval's trusted `Challenge.lean`), so removing them would break that submission. The pool
   forbids `nolint` waivers, so this is left as-is and flagged for the maintainers rather than
   silently worked around. Every other runLinter finding — 54 missing docstrings, 4 underscored
   definition names, 8 simp lemmas out of normal form, ~40 unused instance binders — is fixed.

2. **The pin.** `pool-bump-4.33` carries the v4.32.2 → v4.33.0-rc1 port. The dominant change is
   that `rw` no longer instantiates a metavariable standing in a *proof-valued* argument, so
   rewrites keyed on lemmas like `MeroGermOn.mk_*`, `restrict_restrict` and `ord_mk` stop matching
   even where the pattern is plainly present. Three fixes work, in order of preference: supply the
   proof arguments explicitly; route through a fully elaborated `have`; or apply the lemma with
   `exact`/`refine`, whose defeq matching is unaffected. About fifteen sites are fixed; the known
   remaining one is `Dbar/DiskAcyclic.lean:234`.
3. **The 200-line proof cap**, 13 declarations, largest 407 lines (`Abel/LinkData.lean`). The
   technique that worked for `LaurentTail.tailToH1_alpha` — extracting the large `have` blocks
   into private lemmas in a dedicated section — applies directly; it also relieves heartbeat
   pressure, since the budget is per declaration.

Note that per the pool's `CONTRIBUTING.md`, maintainers bump imported repositories to the pool's
pin themselves, so (1) may not be ours to finish if the proposal is accepted on the "propose a
repo" path.
